How this is applied

Apply writes the file in place, never via a temp-file rename: quickshell watches this path by inode, so a rename would replace the watch and the theme would silently stop updating. The server then asks the shell to switch, and the shell itself runs the external exporter (tmux, Alacritty, niri, guide CSS, icons) — it reads the palette the shell has published, so doing it from here would only race it.
