# CSS-Only Cursor Glow Effects on Waybar

## Overview
Add CSS-only cursor glow effects with trail-like appearance to the waybar using GTK3 CSS.

**Important:** Waybar uses GTK3 CSS engine (not web CSS). No `::before`/`::after` pseudo-elements or `radial-gradient`. We use GTK-compatible properties instead.

## What's Possible (GTK3 CSS)
- `box-shadow` - creates glow aura around hovered modules
- `text-shadow` - glowing text effect
- `background` transitions - color shifts on hover
- `border-color` transitions - border glow
- Transition timing differences create perceived "trail" effect

## Files to Modify
- `waybar/style.css` - Replace existing hover effects with enhanced cursor glow system

## Implementation

### 1. Enhanced Module Hover Glow
Each module gets layered `box-shadow` on hover for a multi-ring glow effect:
```css
#clock:hover {
    box-shadow: 0 0 8px rgba(255,139,74,0.6),
                0 0 20px rgba(255,139,74,0.3),
                0 0 40px rgba(232,93,47,0.15);
}
```

### 2. Background Glow on Container Sections
Section containers (`.modules-left`, `.modules-center`, `.modules-right`) get a background glow when any child is hovered:
```css
.modules-left > widget > box:has(*:hover) {
    box-shadow: 0 0 15px rgba(232,93,47,0.2);
}
```
Note: `:has()` may not be supported in GTK3. Fallback: apply glow directly to each module's container via individual selectors.

### 3. Trail Effect via Transition Timing
- Text shadows: fast fade-in (0.15s), slow fade-out (0.4s)
- Box shadows: medium fade-in (0.2s), very slow fade-out (0.5s)  
- Background: instant change on hover, slow revert (0.3s)
This asymmetry creates a "glow lingers" trail impression

### 4. Cross-module Glow Band
When hovering any module in a section, the entire section container gets a subtle glow, creating a continuous light band:
```css
#custom-logo:hover ~ #niri-workspaces { ... }
```
(CSS adjacent sibling selectors for glow propagation within sections)
