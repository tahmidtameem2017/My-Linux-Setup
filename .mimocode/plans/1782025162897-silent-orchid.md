# Custom Waybar - From Scratch

## Overview
Build a clean, custom waybar from scratch with sunset orange AMOLED aesthetic. Uses existing scripts/modules where available, creates new ones where needed.

## Layout
```
[Logo] [Workspaces] [Window Title]  |  [Clock]  |  [Media] [Volume] [Network] [Clipboard] [Wallpaper] [Battery] [Power]
```

Left: App launcher, niri workspaces, current window
Center: Time + date
Right: Functional modules (media, sound, network, clipboard, wallpaper, battery, power)

## Files to Create/Modify

### Config
- `waybar/config` - New flat config (overwrite existing)
- `waybar/style.css` - New stylesheet (overwrite existing)

### New Script
- `waybar/scripts/clipboard.sh` - Clipboard history picker (cliphist + fuzzel)

## Reused Existing Files (no changes needed)
- `waybar/modules/window_info.py` - Current app display
- `waybar/modules/media-player.py` - Media player
- `scripts/change-wallpaper-simple.sh` - Wallpaper changer
- `scripts/set-volume.sh` - Volume control

## Aesthetic
- AMOLED black background (#000000)
- Sunset orange palette: #E85D2F, #FF8B4A, #F7C7A1, #3D2B24, #7C8A6A
- Sharp corners (border-radius: 0)
- 1px borders for containers
- JetBrainsMono Nerd Font
- Hover effects: text glow, background shifts
- Critical battery pulse animation

## Verification
1. Run `~/.config/waybar/toggle-waybar.sh` to restart waybar
2. Verify all modules display correctly
3. Test click actions (fuzzel, nmtui, clipboard, wallpaper)
4. Test scroll actions (volume)
5. Test hover effects
