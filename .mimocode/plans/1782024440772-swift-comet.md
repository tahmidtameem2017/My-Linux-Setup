## 3. Keybindings (`niri/binds.kdl`)

### Add screenshot to clipboard (requires grim+slurp):
```kdl
Mod+Shift+S  { spawn-sh "grim -g \"$(slurp)\" - | wl-copy"; }
```

### Add window pinning:
```kdl
Mod+Shift+F  { toggle-window-floating; }  // Already have Mod+T for this
```

### Add vim-style focus (keep existing arrows too):
```kdl
Mod+H        { focus-column-left; }
Mod+J        { focus-window-down; }
Mod+K        { focus-window-up; }
Mod+Shift+H  { focus-column-right; }
```

### Add workspace quick-switch:
```kdl
Mod+1        { focus-workspace 1; }
Mod+2        { focus-workspace 2; }
Mod+3        { focus-workspace 3; }
Mod+4        { focus-workspace 4; }
Mod+5        { focus-workspace 5; }
Mod+6        { focus-workspace 6; }
Mod+7        { focus-workspace 7; }
Mod+8        { focus-workspace 8; }
Mod+9        { focus-workspace 9; }
Mod+0        { focus-workspace 10; }
```

### Add Do Not Disturb toggle:
```kdl
Mod+N  { spawn-sh "dunstctl set-paused toggle && notify-send -a dunst 'Dunst' \"$(dunstctl is-paused && echo 'Do Not Disturb ON' || echo 'Do Not Disturb OFF')\""; }
```

### Add niri config reload:
```kdl
Mod+Ctrl+R  { spawn-sh "niri msg action reload-config"; }
```

## 4. Window Rules (`niri/rules.kdl`)

Add rules for common apps:
```kdl
// Firefox - open maximized
window-rule {
    match app-id="org.mozilla.firefox"
    open-maximized-to-edges true
}

// Discord - open maximized
window-rule {
    match app-id="com.discordapp.Discord"
    open-maximized-to-edges true
}

// Spotify - open maximized
window-rule {
    match app-id="com.spotify.Client"
    open-maximized-to-edges true
}

// Telegram - open maximized
window-rule {
    match app-id="org.telegram.desktop"
    open-maximized-to-edges true
}

// File chooser dialogs - floating
window-rule {
    match app-id="xdg-desktop-portal-gtk"
    open-floating true
}

// Picture-in-Picture floating
window-rule {
    match title="Picture-in-Picture"
    open-floating true
    geometry-corner-radius 12
}
```
